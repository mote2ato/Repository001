## 時刻をこう決めた理由

### Threads = 21:10 を基準にした
- スキルの実測値どおり **火・水・木の21:00〜23:00** が閲覧者数で突出している（各4,500〜4,700人）。
- ただし毎日 21:00 ちょうどは競合が最も密集する分。10分ずらして 21:10 を基準にした。
- **9/24（木）だけ 21:05** に前倒し。今週唯一の「普通の平日の木曜21時台」で、いちばん読まれる枠。
  リポストを取りたい「リテイクと仕様変更」をここに置く運用メモの方針に合わせた。
- **9/25（金）だけ 20:40**。金曜夜は21時以降に外出・離脱が進み、投稿後60分の滞在を確保しにくい。
  Threadsは投稿後60分が以降数日の配信量を決めるため、滞在が読める時間に寄せた。
- 9/22（火）・9/23（水）は祝日のため平日夜の動きとは変わる可能性がある。
  火・水はもともと最良枠なので基準どおり置くが、**インサイトは翌日に必ず確認**して、
  想定より閲覧者が薄ければ来週以降は祝日を20時台に寄せる。

### X = 19:30 に固定した
- Xは「著者が返信に返信」が最高重み、かつ**投稿48時間でランキング対象外**。
  時刻の最適化よりも、**投稿直後1時間に著者が返信できる**ことのほうが効く。
- 19:30 に出せば、20:30 までのX返信対応が終わってから Threads（21:05〜21:10）の
  勝負の60分に入れる。同じ夜に両方の初速対応を重ねずに済む。
- 毎日同じ時刻にすることで、読者側に枠を覚えてもらう狙いもある。

## 投稿後の運用（毎日共通）

### X
- 返信が付いたら**必ず著者から返す**（最高重み）。
- チェックは **投稿1時間以内（〜20:30）** と **24時間以内** の2回。
- 通常投稿にURLは入れない（URL単独誘導はリーチが落ちる：インプレ中央値 58 vs 79）。

### Threads
- **投稿後60分**が以降数日の配信量を決める。
- **ピン留めコメントは投稿後5分以内**に置く。
- **リプライへの返信は30分以内**。

## 予約投稿の入れ方（手動）

- **X**：投稿画面のカレンダーアイコン → 日時を指定 → 「予約設定」。
  下書きだけ残す場合は「下書き」に保存し、投稿時刻は上表を見ながら手動で出す。
  ※ Xの予約投稿は本文の改行がそのまま保持される。貼り付け後に空行が詰まっていないか確認する。
- **Threads**：投稿画面の「…」→「スケジュール」から日時指定（最大75日先まで）。
  予約投稿では**ピン留めコメントを同時に仕込めない**ため、
  5分以内に置く運用を守るなら手動投稿のほうが確実。
