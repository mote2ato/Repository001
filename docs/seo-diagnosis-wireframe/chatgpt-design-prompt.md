# ChatGPTへのUIデザイン依頼文

ワイヤーフレームをもとに、ChatGPTにビジュアルデザインを依頼するための指示文です。

## 使い方

1. ChatGPTの新しいチャットに `wireframe-all.md` を添付します。
2. 下の「依頼文1」を貼って送ります。最初に方向性を3案出してもらいます。
3. 3案から1つを選び、「依頼文2」を送ります。デザインの決まりごと（デザイントークン）と部品を作ってもらいます。
4. 最後に「依頼文3」で画面ごとのモックアップを作ってもらいます。

一度に全部を頼むと、画面数が多いため途中で省略されがちです。3回に分けて送るのがおすすめです。

モックアップは画像ではなくHTMLとCSSで作るよう指定しています。画像生成では日本語の文字が崩れやすく、価格などの数字が変わってしまうことがあるためです。ChatGPTのCanvasで開けば、その場で表示を確認できます。

## 依頼文1　方向性の提案

```
添付の「wireframe-all.md」は、診断アプリのワイヤーフレームです。これをもとに、UIのビジュアルデザインをお願いします。今回はまず、デザインの方向性を3案出してください。

■ アプリの概要
・「SEO AIO AEO LLMO診断アプリ」。URLを入力すると、サイトを実際に取得して、SEO、AIO、AEO、LLMOの4つの視点で各100点で採点し、総合スコアとランクS〜Dを出します。
・目的は、診断を入口に「さいたまホームページ相談室」の無料診断の申込を得ることです。
・利用者は、さいたま市内の中小企業と個人事業主の経営者です。ホームページの専門用語には詳しくありません。主にスマートフォンで使います。

■ デザインで大事にしてほしいこと
1. 信頼感。診断は実測で、推測の値は出しません。怪しい無料診断に見えないこと。
2. 押し売りに見えないこと。申込ボタンを派手にしすぎず、結果を読んだ人が自然に相談したくなる見せ方にしてください。
3. 専門用語に詳しくない経営者でも、結果画面を開いてすぐに「点数」と「次に直すこと」が分かること。
4. スマートフォンでの読みやすさを基準にすること。デスクトップ版はそれを広げる形で考えてください。

■ 各案に書いてほしいこと
・方向性の名前と、ねらい（2〜3行）
・配色（主となる色、補助の色、背景、文字の色）。色の値も書いてください
・フォントの方針（日本語フォントの候補と、見出し・本文の使い分け）
・角の丸み、影、余白の考え方
・この方向性がこの利用者に合う理由と、注意点

まだ画面のモックアップは作らないでください。方向性の比較だけで大丈夫です。
```

## 依頼文2　デザイントークンと部品

```
案{番号}で進めてください。次に、デザインの決まりごとと部品を作ってください。

■ 作ってほしいもの
1. デザイントークン
   ・色（役割ごとに名前を付ける。例：背景、面、文字、補助文字、線、主ボタン、リンク、判定ラベル4種）
   ・文字の大きさと太さの段階、行間
   ・余白の段階、角の丸み、影
   ・ライトモードとダークモードの両方
2. 部品のビジュアル仕様
   ワイヤーの「コンポーネント一覧」（C01〜C28）にある部品のうち、少なくとも次のものを、状態ごと（通常、空、エラー、読み込み中など）に示してください。
   ・URL入力フォーム、進捗表示
   ・スコアゲージ、カテゴリバー、実測サマリー
   ・判定ラベル（合格、要改善、不合格、確認不可）
   ・優先改善カード、チェック行、カテゴリ切替（タブ）
   ・対応表の行、プラン比較カード、特典ブロック
   ・CTAボタン（LINE用、フォーム用）、モバイルの固定CTAバー
   ・申込フォームの入力欄とエラー表示、送信完了表示、履歴行

■ 守ってほしいこと
・判定ラベルは、色だけで区別しないでください。ワイヤーにある記号（✓ △ ✕ ？）と文字を必ず残してください。確認不可は点線の枠です。
・文字と背景のコントラストは、WCAG 2.2のAA（本文4.5:1以上）を満たしてください。
・タップできる部品は、高さ44px以上にしてください。
・LINEボタンにLINE社のロゴや公式の緑色を使う場合は、LINE社のガイドラインに沿う前提で、使い方を注記してください。

成果物は、HTMLとCSSで作った1枚の「部品一覧ページ」にしてください。CSSの冒頭に、デザイントークンをCSS変数としてまとめてください。
```

## 依頼文3　画面のモックアップ

```
決めたデザイントークンと部品を使って、画面のモックアップを作ってください。ワイヤーの9画面が対象です。

■ 進め方
・まず「画面3 診断結果」を、画面5（対応表）と画面6（料金・CTA）まで含めた1枚の結果ページとして、モバイル版（幅375px）で作ってください。いちばん重要な画面です。
・確認後に「続けて」と送るので、残りの画面を順に作ってください。順番は、画面3のデスクトップ版（幅1280px）→ 画面1 → 画面2 → 画面4 → 画面7（入力、エラー、送信中、送信失敗、送信完了）→ 画面8 → 画面9 です。
・画面ごとに、HTMLとCSSで作ってください。

■ ワイヤーから変えないこと
・情報の並び順、画面の構成、ボタンの数と置き場所は、ワイヤーのとおりにしてください。より良い配置があると思った場合は、モックアップには反映せず、最後に「提案」として分けて書いてください。
・モバイルでは、結果画面の「優先して直したいポイント」を「実測サマリー」より先に出します（ワイヤーの注記どおり）。
・申込ボタン（LINEとフォーム）は画面6の1か所と、モバイルの固定CTAバーだけに置いてください。結果の途中に大きな申込ボタンを増やさないでください。

■ 文言と数字
・次の料金と条件は、一字一句このとおりにしてください。変えたり、別の数字を足したりしないでください。
  基本プラン 月額33,000円（税込）／専属担当プラン 月額55,000円（税込）／初期費用0円／制作費24回分割、保守を含む月額制／モニター特典 先着3社限定で月額10,000円引き×6か月／無料診断と構成案の提示は無料
・LINEの相談窓口は @113ssawj、リンク先は https://line.me/R/ti/p/@113ssawj です。
・ワイヤーで「{要確認}」や「{ }」になっている部分は、勝手に埋めずにそのまま残してください。仮の値（例：総合78点、ランクA）はワイヤーの例をそのまま使ってください。
・割引後の金額（例：23,000円）は計算して表示しないでください。

■ 入れないもの
・ワイヤーにない機能（PDF出力、ログイン、決済、メール配信、複数URLの一括診断、他社との比較レポートなど）は画面に足さないでください。
・お客様の声、導入実績、写真など、ワイヤーにない要素も足さないでください。必要だと思う場合は「提案」として最後に書いてください。

■ 各画面に添えてほしいこと
・ワイヤーから見た目以外で変えた点があれば、その箇所と理由
・使った部品の名前（C01〜C28）
```

## ChatGPTの出力を確認するときのチェックリスト

- [ ] 料金、特典、LINEのIDとリンク先がワイヤーと一字一句同じか
- [ ] 判定ラベルが、白黒でも記号と文字で区別できるか
- [ ] 結果画面のモバイル版で、総合スコア、いちばん低いカテゴリ、優先改善の1件目が最初に見えるか
- [ ] 申込ボタンが画面6と固定CTAバー以外に増えていないか
- [ ] SEO、AIO、AEO、LLMOの一言説明が、カテゴリ名の下に常に出ているか
- [ ] ワイヤーにない機能や要素が足されていないか
- [ ] 「{要確認}」の部分が勝手に埋められていないか
